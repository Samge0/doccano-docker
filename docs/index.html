核心特性

依赖修复

更新了官方镜像的 pip 依赖，修复 Custom REST Request 功能的数据加载问题。

即插即用

单个 Docker 命令即可启动，包含所有必需的环境配置和依赖。

数据持久化

支持数据卷挂载，确保您的标注数据安全持久，容器重启不丢失。

快速开始

1

运行 Docker 容器

docker run -itd --name doccano \
-e "ADMIN_USERNAME=admin" \
-e "ADMIN_EMAIL=admin@example.com" \
-e "ADMIN_PASSWORD=password" \
-v ~/doccano/db:/data \
-p 8000:8000 samge/doccano:1.8.4
环境变量配置 数据卷挂载 端口映射
2

访问 Web 界面

容器启动后，在浏览器中打开以下地址：

http://127.0.0.1:8000/

使用配置的管理员账户登录即可开始标注

3

验证修复

登录后，创建一个项目并添加 Custom REST Request。现在应该能够正常加载数据，不再出现 "no data available" 错误。

常见问题

为什么需要这个修复版？
官方 doccano:1.8.4 镜像在使用 Custom REST Request 功能时会出现 "no data available" 错误。这是因为镜像中的某些 pip 依赖版本不兼容。我基于官方镜像更新了这些依赖，修复了这个问题。
数据存储在哪里？
通过 -v ~/doccano/db:/data 参数，所有数据都会持久化到您主机的 ~/doccano/db 目录。即使删除容器，数据也不会丢失。
如何修改管理员密码？
在运行 Docker 命令时，通过环境变量 ADMIN_PASSWORD 设置。如果容器已经运行，可以删除容器后重新创建并指定新密码。
这个镜像与官方镜像有什么区别？
唯一的区别是更新了 pip 依赖以修复 Custom REST Request 的数据加载问题。其他功能、配置和使用方式与官方镜像完全一致。
